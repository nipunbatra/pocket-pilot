What stays in my browser?

The game, sounds, and run history stay in your browser. For cloud models, the selected image or structured scene and your API key go to OpenRouter for inference. Local WebGPU models need no key and keep inference on your device; their initial model downloads come from Hugging Face. OpenRouter and the chosen model provider apply their own data policies. This page does not save your key, use analytics, or upload your history. The page’s JavaScript can access a key while connected, so use a dedicated key with a credit limit and disconnect on shared computers. Export a run before refreshing to keep its history; exports contain game inputs and answers, never your key.

What speeds up? What does the model see?

1×, 2×, 4×, 8× and 16× change road speed between decisions. API latency is real and is never divided by the speed setting. Only one request is in flight at a time.

Image mode sends a PNG. Structured scene mode sends obstacle lanes and coordinates as JSON, with no image; Jev uses this mode because it is text-only. Compare Luna and Jev using the same structured input to compare their decision latency. A text result is not a vision accuracy result. Both modes include the selected one, two or three questions. The display stays HD; the API image can be compact or full resolution. Image mode sends no obstacle coordinates. Neither mode supplies the chosen answer label. The chosen lane becomes a left / stay / right steering command in game code. One answer controls the entire lane change. The default takes two looks: when the barrier appears and before it reaches the car. Teaching tour adds a middle look; Fast pass takes one. These distance checkpoints arrive sooner at higher speeds. The countdown is computed locally, excludes API waits, and is never sent to the model.

Classroom mode freezes both the road and game clock during every API request. It resumes from the same position when the answer arrives. Real-time mode keeps moving during requests and skips rechecks that cannot finish within the measured latency plus steering budget. It always requests a first decision for a new barrier. Neither mode changes a model’s chosen lane. When a response arrives, code checks whether the captured obstacle row still exists and the run is still active. Old responses are logged and skipped. A valid response can still be wrong and cause a collision.

Each run stops on a collision, an API error, or after 30 calls. Pause stops new calls. Calls already in flight are still recorded. The two other questions describe the scene; only the open-lane choice steers.

Chat LLM / VLM baseline
GPT-4.1 and Mini use ordinary chat completions with a JSON schema. Image input tests vision; structured JSON tests language reasoning. Chat returns a lane, a boolean and a level index. No class probabilities or confidence are requested or invented. Full JSON shows the exact request and raw response; Full frame also contains the app’s parsed answers. Chat supports structured outputs too; latency depends on the model, provider and workload.
choice → open lane
choice is one supplied label. probabilities maps every label to a probability. A separate confidence is also returned.
noul → middle lane blocked?
noul: 0.9 means estimated 90% probability of “yes”. It is a number, not a boolean. Noul has no separate confidence field.
score → vertical position
Three ordered levels have indices 0, 1, 2. score = Σ(index × probability). It may be fractional; it is not P(danger).
null, missing, false and zero
In our local metadata, provider_processing_ms: null means unknown. It does not mean zero time. Missing middle_blocked.confidence means the field is absent. Neither is Jev’s noul type.
metadata belongs to its source
Model, provider, request ID, tokens and cost are displayed when the selected provider supplies them. Full JSON preserves the OpenRouter response for every model. Frame ID, speed, timestamps, network duration and application outcome are measured by this app.
OpenRouter format vs direct OpenAI
OpenRouter uses state, keyed questions, criteria, and noul. Direct OpenAI uses input, a named questions array, choices / levels, and predicate. OpenRouter translates the model’s interface.

Decisions vs a full LLM / VLM
Same frozen input and questions → Luna Decisions, GPT-4.1, and GPT-4.1 Mini. JSON input tests language reasoning; image input tests vision. The road pauses, request order rotates, and no comparison answer steers.
How this comparison works
Chat uses short, schema-constrained JSON at temperature 0, with a 120-token cap and no requested explanation. It returns a lane, an optional boolean, and an optional level; Decisions also provides probabilities. This compares complete model + API paths, not API overhead in isolation.
Run a matched comparison or inspect the recorded calls. Lower latency is a hypothesis to test, not an assumed result.
