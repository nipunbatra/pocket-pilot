THE GAME IS REAL. THE CONTROLLER IS THE EXPERIMENT.
From a road lane to thirteen button combinations.
This is the PlayMario HTML5 remake running directly on this site: its original maps, enemies, collisions, power-ups and audio. No iframe, remote game page or ROM. Pick any of the 32 worlds above.
Play manually first. Then try a model with JSON describing visible objects, or with the exact screenshot, including the player marker and motion strip. Classroom mode freezes during inference, then applies a command for 4, 8 or 16 frames. Real time keeps the previous command active while an answer is pending; start at 1×. Each model jump command can wait up to six frames for landing, so a jump request is not silently lost just before touching ground. Manual play keeps native held-button controls.
The road fine-tunes remain in the Road lab. They predict lanes and have not been trained for Mario. Liquid here uses original 600M weights. Model gameplay is experimental; this is not a claim that they can finish every level. Mario fine-tuning plan ↗
